# Portal i18n

## Adding user-visible text

1. **Modals, sentences, errors** — add keys under `src/i18n/portalNamespaces/` (or `resources.ts` / `faResources.ts` / `wave1Resources.ts`) and use `useTranslation('namespace')`.
2. **Short labels reused across screens** — add a row to `healthPlanPhrases.ts` (5 columns: en source key + es, fr, ar, fa) and render with `uiText('English label')`.
3. Do **not** add new strings only to `faPhrases.ts`; that catalog is legacy extraction.

## Locales

Wave-1 UI: `en`, `es`, `fr`, `ar`, `fa`. Clinic language is applied via `ClinicLocaleSync` and `applyUiLocale`.

## AI-generated content

Stored report/plan prose follows `clinics.default_content_locale`. After changing clinic language, **rescore / regenerate** plans so new text is generated; UI translation does not rewrite stored English.
